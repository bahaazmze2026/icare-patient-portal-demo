# i-CARE Cloudflare Pages (demo only)

This repository is a **synthetic-data demonstration**. No real patient or staff data should be entered.

Connect this GitHub repository to Cloudflare Pages. Use production branch `main`, Framework preset `None`, leave Build command blank, and set the output directory to `/`.

The public site includes client-side demonstrations only; it is not a real authenticated medical portal.

Future production deployment requires a secure backend, private file storage, access-control enforcement and audit controls.
