# i-CARE Patient Portal — V7 Demo

**Arabic / العربية**

هذه النسخة نموذج تفاعلي توضيحي فقط لبوابة استلام نتائج التحاليل.

- تحتوي على **بيانات وهمية فقط**؛ لا يوجد اتصال ببرنامج i-CARE NEO أو قاعدة بيانات المرضى.
- **غير مخصصة للاستخدام الطبي الفعلي**، ولا يجوز إدخال بيانات مرضى أو كلمات مرور حقيقية.
- لا توجد مصادقة إنتاجية أو خدمة خلفية لحفظ تقارير المرضى.
- الشعار الأصلي محفوظ داخل `index.html`.
- لا تُخزّن أي ملفات طبية في هذا المستودع.

**Live site (when Pages deployment succeeds):**

https://bahaazmze2026.github.io/icare-patient-portal-demo/

**Deploy:** GitHub Actions workflow in `.github/workflows/deploy-pages.yml`. If Pages is not activated, open **Settings → Pages** and choose **GitHub Actions** as the build source. Check the **Actions** tab for the deployment result.

For actual patient reports, use a separate secure backend and private storage after the required security and privacy validation.
